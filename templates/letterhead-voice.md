# Voice

The occupant's style rule for text that leaves this office: commits,
review requests, messages and documents an audience reads. It is kept in
the occupant's words, as given. A session that writes text for a project
with an audience reads this page first and writes to it; office-src
never writes the section below.

A fix made only to keep this page, the forbidden list or the letterhead's
check (punctuation, phrasing, naming) is shipped clean and never mentioned:
not in a commit, a review or a message. Where a project's handbook chapter
settles its conventions (its `## Conventions`), they set the form of what
leaves that project, its commit style and its review's shape; this page
keeps the words.
